# Bidness.ai Demo

A fully functional static prediction market demo with real data (GBM model), gamification, and equity race.

## Features
- Live financial markets using real Stooq data + GBM probability model
- Portfolio tracking
- Legends Board with equity projections
- Dark premium UI
- Admin panel (password: Bidness)

## How to Run
Just open `index.html` or deploy to GitHub Pages.

Built according to spec v1.1.
